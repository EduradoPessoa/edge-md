# Política de segurança

## Versões com correção

Só a versão mais recente recebe correções de segurança.

## Como relatar uma vulnerabilidade

**Não abra issue pública.** Use o
[relato privado](https://github.com/EduradoPessoa/edge-md/security/advisories/new)
do GitHub. Informe versão, sistema, passos para reproduzir e impacto.

Resposta em até 7 dias. Quando houver correção, ela sai numa nova versão, com crédito a quem relatou, se desejado.

## Sobre os instaladores

Os instaladores ainda não têm assinatura de código; o Windows SmartScreen pode avisar.
Confira o SHA-256 publicado em cada Release antes de instalar.
