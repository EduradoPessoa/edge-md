# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Resumo: seja respeitoso, aceite críticas técnicas com maturidade e não pratique assédio ou discriminação.

Relatos de comportamento inaceitável: use o [relato privado](https://github.com/EduradoPessoa/edge-md/security/advisories/new) ou contate o mantenedor pelo perfil do GitHub. Os mantenedores podem remover comentários, issues e PRs que violem estas regras.
